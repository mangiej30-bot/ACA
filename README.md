# ACA Servidores y Servicios Web - Ferretería El Tornillo

Sitio web moderno, limpio y profesional para el cliente **Ferretería El Tornillo**, desarrollado utilizando exclusivamente tecnologías web estándar sin dependencias externas.

## 📁 Estructura del Proyecto

`	ext
ferreteria-el-tornillo/
├── index.html
├── css/
│   └── estilos.css
└── js/
    └── contacto.js
`

## 📋 Secciones del Sitio

1. **Inicio:** Información del negocio, eslogan, horarios de atención y acceso directo al catálogo.
2. **Productos:** 4 categorías principales (Herramientas, Pinturas, Tornillería y Material eléctrico) presentadas en tarjetas interactivas.
3. **Contacto:** Dirección física, horario, mapa esquemático y formulario validado en tiempo real con JavaScript vanilla.

## 🛠️ Tecnologías

- **HTML5:** Semántico y accesible.
- **CSS3:** Variables de diseño, efectos hover suaves y 100% responsive.
- **JavaScript Vanilla:** Validación en el navegador (mínimo 2 caracteres en nombre, control de errores y alerta de confirmación).

## 🚀 Cómo Visualizar

Simplemente abre el archivo erreteria-el-tornillo/index.html en tu navegador favorito. No requiere instalación, servidor ni bases de datos.
